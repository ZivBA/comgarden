# 🌱 גן קהילתי — כלי תכנון חזון

אפליקציית ווב פשוטה המאפשרת לחברי קהילה לתכנן ולשתף את החזון שלהם לגן הקהילתי.

## איך זה עובד?

1. פותחים את האפליקציה בטלפון
2. רואים את התצלום האווירי של מיקום הגן
3. גוררים "מדבקות" של עצים, ערוגות, ספסלים ועוד אל התמונה
4. משתפים את החזון שלכם בוואטסאפ הקבוצתי
